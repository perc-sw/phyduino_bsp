Notes

Board tested One Phyduino Pico, 2026-10-05, 2026-10-08 and 2026-10-09 (dates in the table are 2026).
A3–A5 pull-downs On this board R47–R49 (100 kΩ) appear not to be connected, so unconnected A3–A5 inputs float. Hardware, not firmware.
Windows Smart App Control Blocks the unsigned picotool used to build the UF2. Turned off on the development PC; distribution fix still open.
First PD contract current On plugging into a charger the first 20 V contract asks 1000 mA, although the profiles (from the chip's NVM) read 20 V/0.5 A; after setProfiles() renegotiates it asks 500 mA. Cause not known yet.
Pico 2 used for 13–15 Its GP0 (pin 1) does not transmit, so for 14–15 the bridge used Serial1.setTX(12) (pin 16) instead. That board only; a working Pico 2 uses the wiring shown.

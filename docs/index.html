Introduction to Electronics - Arduino board package

Arduino IDE support for the student-workshop boards. The package is a standalone Arduino core built directly on the Raspberry Pi pico-sdk, so a sketch can use the Arduino API (digitalWrite, analogRead, Serial, SPI, Wire) and the pico-sdk (#include "hardware/pwm.h") side by side. Upload copies the program to the board's USB drive, so no driver is needed.

Arduino core pico-sdk 2.2.0 RP2040 Windows · Linux · macOS v0.1.0-rc.2

Install in the Arduino IDE

  1. 1 Open File → Preferences and add this line to Additional boards manager URLs:
    https://github.com/perc-sw/phyduino_bsp/releases/download/v0.1.0-rc.2/package_phyduino_index.json
  2. 2 Open Tools → Board → Boards Manager, search for Phyduino and click Install.
  3. 3 Select Tools → Board → Phyduino Boards → Phyduino Pico.
  4. 4 Upload a sketch. If the board does not respond (first upload, or a sketch that crashed), slide SW1 to GND (BOOTSEL), press reset (SW2), upload, then slide SW1 back to 3.3 V.
